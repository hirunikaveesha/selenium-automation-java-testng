# Selenium Automation with Java, TestNG & Maven

## 📌 Project Overview

This repository contains my hands-on Selenium WebDriver automation practice using **Java, TestNG, and Maven**.

The project was created to strengthen my practical knowledge of web automation testing by implementing Selenium concepts from **fundamentals to advanced automation techniques**.

The project focuses on writing maintainable and reusable automated test scripts and applying automation framework concepts such as **Page Object Model (POM), TestNG, Maven, and Data-Driven Testing**.

---

## 🎯 Project Objectives

- Build practical knowledge of Selenium WebDriver using Java
- Understand and implement Selenium WebDriver concepts
- Automate web application test scenarios
- Learn and apply TestNG for test execution and organization
- Manage project dependencies and execution using Maven
- Implement Page Object Model (POM)
- Practice reusable and maintainable automation code
- Implement Data-Driven Testing
- Understand automation framework structure and best practices
- Build a portfolio project demonstrating Selenium automation skills

# 🏗️ Page Object Model (POM)

The project applies the **Page Object Model** design pattern to improve test code organization, reusability, and maintainability.

### POM approach

- Separate page locators from test cases
- Create reusable page classes
- Encapsulate page interactions
- Keep test cases focused on test flow
- Reduce duplication
- Improve maintainability when UI elements change
